The carrot, at every size it ships

  • Activity Bar: the single-colour icon.svg. VS Code paints Activity Bar icons in the theme's own foreground, so colour is never ours to choose there. Drawn at 2× (28×20) so every pixel lands on whole screen pixels.
  • Sidebar header: the colour rabbithole-icon.svg at 3×, with an orange phosphor glow in dark themes. This is the only place inside the editor where the full-colour carrot can appear.
  • Status bar: today it's the 🥕 emoji, which looks different on every OS. Registering the carrot as a one-glyph icon font (contributes.icons) would put the pixel carrot there instead, as $(rabbithole-carrot). It would be single-colour, like the Activity Bar.
  • Marketplace: the 128×128 icon.png should be this carrot at 8× (112×80), centred on a solid tile, which keeps its edges sharp.

What changed from today's sidebar

  • The 🔥 and the 🥕 emoji are replaced by the pixel carrot and plain block characters, so the panel looks the same on Windows, macOS and Linux.
  • The donut becomes one split bar plus a list. A donut at 72px can't show two projects that differ by 10×; the list carries the numbers.
  • The 7-day line becomes a column graph built from eighth-block characters (▁▂▃▄▅▆▇█), four rows tall. Today is amber, matching the heatmap.
  • New: a half-hour day tape, the same one as on the dashboard, so “when did I work” is answered without opening it.
  • Hover a project (a row or segment under “projects today”, or a key under the week) and today's time, the target meter, the day tape, lines and the week all narrow to that project, measured against its own target. The week keeps its scale, so a project shows as its share of each day.
  • Below 230px the streak shows 7 days instead of 14, the graph drops its axis, and every other hour label goes. Drag the width slider to see it.
  • The CRT layers are the dashboard's, scoped to the sidebar. They follow the same display setting.

All numbers are example data matching the dashboard mockup.
