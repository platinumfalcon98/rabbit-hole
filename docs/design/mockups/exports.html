Fits inside the extension

  • The current exports don't use Chart.js. The share card is drawn on a canvas at 3× and the report is built with jsPDF, and both stay that way: only the drawing changes, from Press Start 2P, Unica One and Electrolize to Martian Mono, box-drawn panels and block glyphs.
  • The share card is always the dark phosphor screen, whatever the editor theme, because it is an image people post. It keeps faint scanlines but no phosphor mask, which would moiré once a social site rescales it.
  • The report keeps today's dark pages and their hairline terminal frame, now with TTY panels inside. It stays flat: no glow and no scanlines, which don't survive PDF viewers and printing. jsPDF needs a static TrueType file, so the report embeds a regular and a bold instance of Martian Mono cut from the variable font.
  • One day gets the day tape; a range gets one column per day (green: target met). The report adds sessions or days, top files as git diff --stat, and a heatmap for 30 and 90 days.
  • CSV and JSON keep today's columns and shape, plus the new per-session languages.

All numbers are example data, matching the dashboard mockup.
